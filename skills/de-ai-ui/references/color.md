# 颜色 / Color

主要来源：@ianneo_ai（黑白灰）、@ZaynHao（成套色阶与基础色）。要点转述，原帖见 `sources.md`。

## 1. 界面退后：chrome 只用黑白灰

界面骨架——按钮、卡片、输入框、导航——默认只用白与灰阶；颜色留给照片、插画、数据可视化等**内容**。

为什么有效：AI 默认爱给每个元素上色（渐变按钮、彩色图标、一卡一色），每个元素都抢眼，结果整体显廉价。让界面安静下来，内容的颜色自然成为主角。[@ianneo_ai]

延伸细节：界面明暗可以随内容情境变化（例如进入夜景内容时整体随之变暗、地图转黑底），而不是机械地硬切一个深色模式。[@ianneo_ai]

## 2. 颜色用成套色阶，不随手写 hex

- 把页面用到的颜色全部换成一套有用途定义的色阶 token，并按用途用色。[@ZaynHao]
- 他使用的是 Radix Colors：12 个等级按使用场景分组（如应用背景、组件背景、悬停背景、边框、实色、文字等），照定义用就不容易搭错。具体每级用途以 Radix 官方文档为准。
- 判断标准：代码里出现脱离 token 的裸 hex，基本就是要收编的对象（品牌素材色、内容图除外）。

## 3. 先定 3–5 个基础色

为应用挑 3–5 个有辨识度的颜色定整体基调，再从色阶系统派生其余颜色。取色思路之一：从自己喜欢的网站 / 应用里提取颜色（原帖作者举了自家应用背景色的例子）。[@ZaynHao]

## 4. 明确禁用

- 紫色 / 紫蓝渐变（页面、按钮、标题都不行）[@dingyi][@Xian0063]
- 渐变按钮、彩色图标雨、一张卡片一个颜色 [@ianneo_ai]
- 单独给某个字染色来「制造设计感」[@Xian0063 转述的拦截项]
