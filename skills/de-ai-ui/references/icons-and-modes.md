# 图标与多模式素材 / Icons & mode assets

主要来源：@Kubai087（改造 AI 图标）、@yanliudreamer（图标体系）、@remixdesigner / @ianneo_ai（多模式）。要点转述，原帖见 `sources.md`。

## 1. 同一套图标，同一个风格体系

- 一整套界面里的图标应来自同一风格体系：线条粗细、填充方式、圆角、比例、视觉重量一致，不要拼凑。[@yanliudreamer]
- 选图标库时先看它能否覆盖全站需求（如 Remix Icon、The Noun Project 的成套资源），再定使用规范，见 `workflow-and-resources.md`。

## 2. 改造 AI 生成图标：降低非必要的体积表现 [@Kubai087]

AI 容易把简单符号做成带复杂空间与物理结构的「立体物」。改造原则（转述）：

- 主体：非必要不用过多高光、阴影笔触；优先简单的线性或径向渐变构建；非必要不让环境光影响主体。
- 背景：考虑不同圆角下的裁切适配；不用多余的弥散光和材质；渐变取同色相不同亮度，或不同色相但鲜亮的颜色。
- 全局：非必要不用内发光、内阴影体现质感。
- 高光不要只提亮（会发灰）；阴影用相近色相的更深颜色，不要直接掺黑。
- 产出要分层文件 + 背景参数，方便继续适配（如导入 Icon Composer 做液态玻璃适配）。

## 3. 不同模式单独设计素材

- 苹果为 Preview 图标的 Clear 模式单独加了图层，因为默认模式图片直接转换过去会显脏。[@remixdesigner]
- 同理：深色 / 夜间 / 透明模式的素材要单独处理，不要靠滤镜或自动反色硬转。[@remixdesigner][@ianneo_ai]
- 检查方法：每个模式单独截图看，出现灰蒙、脏边、对比塌陷，就是需要单独出图的信号。`[本 Skill 补充]`
