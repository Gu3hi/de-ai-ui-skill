# 工作流、资源与同类 Skill / Workflow, resources & related skills

主要来源：@Xian0063（8 条原则 + 5 个 Skill 的评介）、@yanliudreamer（10 个资源 + 方法转述）。要点转述，原帖见 `sources.md`；第三方工具与 Skill 的最新用法以各自官方文档为准。

## 1. 8 条审美原则（@Xian0063，转述）

1. 从好作品和日常里找需求。
2. 先定义再动手：给谁用、解决什么问题、要什么感觉；写不清就先提问，这一步不出设计。
3. 拆解好设计，不照搬：学原理，不复制画面。
4. 用目标给反馈：在截图上标问题、说想要的效果，具体数值交给 AI 算。
5. 先出全貌，再逐块改：先出完整一版，列问题、排优先级，每轮只改一处。
6. 统一视觉规则：色值、字体、材质先定好，生成素材时也遵守同一套规则。
7. 先上线，再优化：不影响核心体验的问题不阻塞发布，上线后按真实反馈排下一步。
8. 用反馈分配精力：新想法先做小 demo 试水，反馈好持续打磨，反馈差及时停。

配套方法（@yanliudreamer 转述的英文文章要点）：从全局约束出发而不是局部修补；对每个元素做减法审查；在设计工具里一次生成 3–4 个方案对比，避免「原型引力」（在代码里投入太多后只会沿现方案优化）；用组件与设计系统保一致；借鉴成熟产品已验证的 UX。

## 2. 10 个资源（@yanliudreamer）

| 用途 | 资源 | 用法要点（转述） |
|---|---|---|
| 配色 | Coolors — https://coolors.co/ | 生成 / 锁定 / 调整配色组合；分析冷暖、明度、饱和度为什么舒服 |
| 字体 | Fontshare — https://www.fontshare.com/ | 同段文字试 3–5 种字体，比较字重、字宽、字距 |
| 图标 | The Noun Project — https://thenounproject.com/ | 研究抽象概念如何简化成符号；成套界面选同一风格体系 |
| 插画 | Blush — https://blush.design/ | 按品牌色与场景组合；为空状态、引导、成功等场景分别设计 |
| 动效 | React Bits — https://reactbits.dev/ | 拆解动效的触发、速度、节奏与目的，而非只抄效果 |
| 3D | Spline — https://spline.design/ | 从简单几何与材质入手；3D 不抢文字与按钮的注意力 |
| 图片 | Unsplash — https://unsplash.com/ | 看构图、光线、色调与多图的统一视觉语言，不只按主题搜 |
| CTA | CTA Gallery — https://www.cta.gallery/ | 对比同类产品的 CTA 文案、层级与出现时机 |
| 品牌规范 | Frontify — https://www.frontify.com/ | 参考成熟品牌的规范与资产管理，为自己建 Mini Design System |
| AI 交互模式 | The Shape of AI — https://www.shapeof.ai/ | AI 产品的交互模式：何时主动、何时等用户确认、如何保持可控透明 |

## 3. 5 个同类 AI 设计 Skill 怎么选（@Xian0063 的评介，转述）

作者注明：其文中的演示是按各 Skill 官方说明复刻的示意，不是真实运行结果；下列定位按其评介转述，安装方式以各项目官方 README 为准。

| Skill | 定位（转述） | 适合 |
|---|---|---|
| UI UX Pro Max | 一句话需求生成整套设计系统（风格 / 配色 / 字体 / 行业规则） | 不知道用什么风格，想要稳妥专业的结果 |
| Taste Skill | 先定方向再做原创感，多方向提案 + 多宽度截图自查 | 官网、品牌页、作品集 |
| Impeccable | 用命令逐块修已有页面，带规则化 AI 味检测 | 已有项目逐块打磨；可再叠加 Emil 的细节 Skill |
| Emil Kowalski Skills | 专管动效与交互细节的小 Skill 集 | 叠加在其他 Skill 之上补手感 |
| Hallmark | 分级检查（不过线不能上线）+ 改版时核对功能不丢失 | 落地页、预约 / 商店页、有风险的改版 |

与本 Skill 的关系：本 Skill 是一套轻量的「去 AI 味」规则与自查清单，可独立使用，也可与上表任一 Skill 叠加（本 Skill 管判断标准，它们管生成与执行流程）。
