# AI slop 自查清单 / Self-audit checklist

交付前逐项检查，命中即修。A 组转述自 @dingyi 的清单（原帖见 `sources.md`），B 组为其他来源的补充。措辞为转述，顺序与归类为本 Skill 整理。

## A. 典型特征清单（@dingyi）

- [ ] 标签（tag/badge）与斜体字到处都是
- [ ] 用了被用烂的字体：Instrument Serif、Space Grotesk、Bricolage Grotesque
- [ ] 滥用等宽字体做正文 / 标题装饰
- [ ] 细节堆过头：分割线、多层阴影、半透明叠色、带边框的容器
- [ ] 图表做得过度详细
- [ ] 文案过度口语化或随意造词
- [ ] 代码式面包屑、章节编号、标题上方的小眉标（eyebrow）
- [ ] 紫色渐变
- [ ] 全大写的小标题
- [ ] 用中点「·」当分隔符
- [ ] 正文塞 emoji、无用文字堆积
- [ ] hero 区字号大得离谱
- [ ] 冗余的解释性描述文字
- [ ] 嵌套处没做同心圆角
- [ ] 线条 / 边框粗细不统一，该细的地方用了 1px
- [ ] 滚动动效过多、过渡不收敛、生硬
- [ ] 字号超过 4 种且最小低于 12px
- [ ] 卡片左边缘彩色竖线
- [ ] **下拉菜单按钮的下拉小图标没修**（作者认为最普遍、最严重的一项）

> 第 19 条原帖未给具体修法。`[本 Skill 补充]` 检查点：箭头是否与图标库风格一致（不用系统默认箭头充数）、尺寸是否与字号匹配、右侧间距是否与左侧 padding 呼应、是否光学居中、展开状态是否有变化。

## B. 其他来源补充

- [ ] 紫蓝渐变、全部居中排版、卡片套卡片、标题顶 emoji 图标（@Xian0063）
- [ ] 编造的数据 / 社会证明、标题上的英文小标签、单独染色的一个字、结尾硬塞订阅框（@Xian0063 转述的拦截项）
- [ ] 渐变按钮、彩色图标、一张卡片一个颜色——界面骨架抢了内容的颜色（@ianneo_ai）
- [ ] 颜色是随手写的 hex，没有纳入成套 token（@ZaynHao）
- [ ] 没做光学对齐；圆角 / 阴影取值与功能场景不符（@ZaynHao）
- [ ] 需要用户停下来判断的交互过多，或出现的位置不对（@ZaynHao）
- [ ] 圆角不在 4px 网格、同层不一致、小于 4px、pill 没全圆（@Kubai087）
- [ ] 图标混搭不同风格体系，线宽 / 圆角 / 比例 / 视觉重量不一（@yanliudreamer）
- [ ] 深色 / 透明模式只是把默认素材自动转换，显脏（@remixdesigner、@ianneo_ai）
- [ ] 中文字体栈顺序、命名、引号、兜底有问题（@ricouii，见 `typography-cjk.md`）

## C. 汇报格式

自查后按此格式汇报，再按严重程度从高到低、每轮只改一处（@Xian0063）：

```
命中 N 项：
1. [严重] 下拉箭头：系统默认箭头且贴边 → 换图标库 chevron，尺寸与字号匹配，右间距与左 padding 一致
2. [中] 边框粗细不一：.card 1px 与 .input 0.5px 混用 → 全站统一（回退策略见 radius-and-borders.md）
...
```
